# 260818\_분진 탐지 방식 개선

**CNN 이미지 분류 방식**

- 지도학습 기반
- 분진 있음/없음 의 경계가 라벨링 단계에서부터 모호함
- 관측 포인트 마다 배경이 다르고, 개소별 배경을 학습해 버리는것이 아닌가는 의심
- 관측 개소는 고정형이라 같은 위치를 반복 촬영하므로 조명 변화 정도를 제외하면 이미지 다양성 확보가 어려움
- 개소마다 데이터를 수집하고 라벨링을 전부 해줘야 함
- 모델이 업그레이드 되면 이전 출력값과 직접 비교를 할 수 없음

## 포집 마커 방식

### 1. 마커 설계

- 외곽 굵은 사각 테두리
    - 꼭지점 : 정합 기준점 역할
    - 사선으로 촬영된 이미지를 정면 시점으로 보정
    - 실제 인쇄 치수를 알고 있으므로 밀리미터당 픽셀 환산도 결정
    - 테두리를 굵게 잡을수록 기준값이 안정됨
- 모서리 블록 3개
    - 네 모서리 중 세 곳에만 배치
    - 비어 있는 모서리 위치로 패드의 회전 방향을 판정
    - 부착 자세가 틀어져도 판독 좌표계가 흔들리지 않음
- target\_id 숫자
    - 촬영된 이미지만으로 어느 관측 포인트인지 확정
    - 현장에서 부착 위치 확인과 대조에 사용
- 중앙 여백
    - 실제 측정 영역
    - 인쇄물을 최소화해 노출 면적을 최대로 확보
    - 구획 값이 고르게 움직이면 균일 침착, 분포가 벌어지면 국소 뭉침
- 하단 가는 선 4단계
    - 여백 방식과 선군의 감도 방식 비교용 테스트
    - 미세 오염 구간에서 여백보다 먼저 반응하는지 확인
    - 여백 방식이 충분하면 사용 안함
- 바탕과 인쇄 톤
    - 흑색 분진 : 백색 바탕에 흑색 인쇄
    - 백색 분진 : 흑색 바탕에 백색 인쇄
    - 관측 포인트별 분진 색상은 정해져 있으므로 배정은 고정
- 재질
    - 양면 개퍼테이프 (자국이 남지 안도록)
    - 패드 제질 : PP 등 matt한 무광으로(빛반사 없는)

### 2. 이미지 정합 및 탐지 알고리즘

1. **패드 검출**
    1. 이진화(흑백으로 변형) 후 외곽선을 찾고 다각형 근사로 테두리의 네 꼭짓점을 잡음
    2. 모서리를 직접 찾지 않고 네 변 각각에 맞춘 뒤 직선들이 만나는 교점을 꼭지점으로 잡음(굵은 테두리에서 더 안정적)
2. **방향 판정**
    1. 모서리 블럭 3개를 확인하고 비어 있는 모서리 위치로 회전 방향을 확정
3. **정면 보정**
    1. 꼭지점 기준으로 사선 촬영을 정면 시점의 고정 규격으로 다시 그림 (사영변환)
    2. 어느 각도에서 찍었든 동일한 좌표계로 들어옴
4. **품질 검수**
    1. 선명도(초점), 포화 픽셀 비율, 픽셀 크기로 판독 가능 여부 확인
    2. 선명도는 여백이 아니라 테두리 기준으로 측정
    3. 기준 이미지와 판독 이미지의 패드 크기 차이가 크면 촬영 조건이 바뀐 것으로 보아 판독 불가 처리
5. **조명 정규화**
    1. 여백 밝기를 테두리 밝기로 나눠 조명·노출 차이를 소거
    2. 테두리 네 변으로 조명 평면을 추정해 패드 안의 밝기 기울기를 보정(여백 픽셀로 적합하면 균일 침착을 조명 기울기로 오인해 신호를 지움)
6. **인쇄물·포화 영역 제외**
    1. TARGET\_ID와 선군은 측정 여백 안에 인쇄되어 있으므로 마스크로 제외
    2. 정반사로 포화된 구획도 제외(백색 분진으로 오판 방지)
7. **판독값 산출**
    1. uniform : 패드 전체 밝기 변화 기준. 미세 입자가 넓고 고르게 침착된 정도
    2. localized : 붙어 있는 분진 픽셀을 덩어리로 묶어 크기와 짙기 기준. 굵은 입자가 떨어진 정도
    3. 각각 0\~1의 값으로 정규화
8. **종합 지표 계산**
    1. combined = uniform + localized − uniform × localized


### 3. 개소별 지표 관리 방식

1 .개소마다 부착 직후의 청정 상태를 기준점으로 지정한다

1. AMR이 관측할 때마다 기준점 대비 침착량을 계산한다 (2. 이미지 정합 및 탐지 알고리즘)
2. 2의 값을 세 가지로 구분하여 관리한다

1. **절대량** : 기준점 대비 현재 총 침착량. 상태 판정과 포화(패드가 완전히 오염되는 상황)를 감지한다.
2. **추세** : AMR이 관측한 값들 간의 차분. 침착량이 갑자기 크게 느는 (급성 오염)상황을 이 값이 튀는 것으로 잡는다
3. **누적 **: 관측 간 차분을 계속 더해 나간다(CUSUM류 알고리즘). 미세 입자가 관측마다 조금씩 침착되는 만성 상황은, 개별 관측으로는 절대량이나 추세로 관찰할 수 없다. 작은 증분이라도 매번 같은 방향이면 누적값이 기준점에서 한 방향으로 벌어진다.


## 관리 체계

1. 기준점은 고정하고, 패드를 교체할 때만 리셋된다
2. 임계값은 개소마다 자기 기준선으로 자동 산출한다. 누적된 해당 관측 개소의 중간값을 기준으로 평상시보다 몇 배 더 흔들리는가로 판정한다
3. 개소 간 비교는 raw data의 스코어 수준에서는 직접 비교가 불가능하다(촬영 거리, 각도, 조명이 개소마다 고정이라 감도가 다름). 비교는 보정된 등급 수준에서만 성립한다.
