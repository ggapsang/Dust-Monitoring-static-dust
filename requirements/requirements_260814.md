# 참조 패드 판독 모듈 요구사항 정의서

작성일: 2026-08-14
대상: 분진 판독 모듈 개발 담당자

---

## 1. 배경

에코프로비엠 포항공장에 도입 중인 AMR 기반 분진 이상탐지 시스템에서, 기존 AI 기반 분진 탐지 방식(정적 분진 CNN 이미지 분류기, 동적 분진 CV 탐지)의 탐지 성능이 실용 수준에 도달하지 못했다. 원인은 알고리즘 선택이 아니라 문제 설정에 있다. 관측 포인트마다 배경이 다르고 분진이 배경 텍스처와 광학적으로 연속적이어서, 학습 기반 방식은 분진이 아닌 배경을 학습한다. 또한 AMR이 하루 수 회 방문하는 저빈도 관측으로는 연속 현상인 누출을 포착할 수 없다.

이에 관측 대상을 현장 표면 자체가 아니라, 관측 포인트에 부착하는 **참조 패드**로 전환한다. 청정 상태의 외관이 알려진 인공물을 관측하므로 배경 다양성 문제가 소멸하고, 패드가 방문 사이의 시간 동안 분진을 누적하므로 저빈도 관측으로도 유효한 측정이 된다.

이 방식은 침착 분진 측정에 쓰이는 sticky pad 방법론(Beaman & Kingsbury, 1981)과 원리가 같다. 규정된 점착 표면에 분진을 포집한 뒤 반사율 저하를 측정하는 방식이며, 원 방법이 반사계로 읽는 것을 카메라로 읽는 것이 차이다. 학습 요소는 사용하지 않는다.

### 참조 패드 구성

- 불투명 기재에 점착층을 둔 정사각형 패드. 관측 포인트 바닥에 수평으로 부착
- 인쇄 요소: 외곽 굵은 사각 테두리, 모서리 블록 3개, TARGET_ID 숫자, 하단 굵기 4단계 선군(실증용)
- 중앙 여백이 실제 측정 영역
- 관측 포인트별 분진 색상은 고정되어 있으며, 흑색 분진 포인트에는 백색 바탕/흑색 인쇄, 백색 분진 포인트에는 흑색 바탕/백색 인쇄 패드를 배정
- 도안 및 생성 스크립트는 별도 제공

### 측정 원리

분진과 배경이 모두 무채색이므로 신호는 밝기 변화에 담긴다. 여백의 밝기가 청정 상태 대비 얼마나 변했는지를 측정하며, 변화 방향은 패드 톤에 따라 반대다. 카메라 밝기값은 반사율에 조명·노출이 곱해진 값이므로, 같은 이미지 안의 테두리 밝기를 기준으로 나눠 조명 변동을 상쇄한다.

## 2. 개발 범위

### 이번 범위

참조 패드가 촬영된 이미지 파일 1장을 입력받아, 분진 스코어와 판독 부가 정보를 출력하는 단일 모듈.

### 이번 범위 제외

- 이미지 수집 및 저장 연동
- DB 연동, API 서빙, 화면
- 시계열 추세 산출, 교체 이벤트 판정, 알람 판정
- 기준 이미지 관리
- 등급 임계값 설정

제외 항목은 후속 단계에서 이 모듈을 호출하는 상위 계층으로 구성한다. 따라서 본 모듈은 상태를 갖지 않고, 이미지 1장에 대해 독립적으로 동작해야 한다.

## 3. 기능 요구사항

### FR-1 패드 검출

이미지에서 참조 패드 영역을 검출하고 외곽 테두리의 네 꼭짓점 좌표를 구한다. 꼭짓점은 서브픽셀 정밀도로 산출한다. 패드가 검출되지 않으면 판독 불가로 반환한다.

### FR-2 회전 방향 판정

모서리 블록 3개의 배치를 확인하여 비어 있는 모서리를 찾고, 패드의 회전량을 확정한다. 판정에 실패하면 판독 불가로 반환한다.

### FR-3 정면 시점 보정

검출된 네 꼭짓점을 고정 규격 좌표계로 사영변환하여, 촬영 각도와 무관하게 항상 동일한 크기의 정면 이미지를 생성한다. 보정 후 측정 영역 좌표는 고정 상수로 지정 가능해야 한다.

### FR-4 품질 게이트

다음 항목을 산출하여 기준 미달 시 판독 불가로 반환한다. 판독 불가 시에는 어느 항목에서 걸렸는지를 함께 반환한다.

- 이미지 선명도
- 포화 픽셀 비율
- 추정 촬영 각도
- 패드 영역의 픽셀 크기

각 항목의 임계값은 설정으로 외부에서 조정 가능해야 한다. 초기값은 실증 데이터 확보 후 결정하므로, 우선 조정 가능한 구조만 갖춘다.

### FR-5 조도 정규화

테두리 영역의 밝기를 기준값으로 하여 여백 밝기를 정규화한다. 이 처리로 조명 세기와 노출 설정의 변동이 상쇄되어야 한다.

추가로, 여백 안의 밝기 기울기를 보정하는 처리를 포함한다. 조명이 한쪽에서 오는 경우 청정 상태에서도 여백에 기울기가 생기며, 이것이 국소 오염으로 오판될 수 있다.

### FR-6 구획별 측정

여백 영역을 격자로 분할하고 구획별 정규화 밝기를 산출한다. 격자 분할 수는 설정으로 조정 가능해야 한다.

### FR-7 비분진 배제

채도가 임계를 넘는 구획은 분진이 아닌 변색(녹, 유분, 결로 등)으로 분류하여 측정에서 제외한다. 포화된 구획(정반사)도 제외한다. 제외된 구획 수를 함께 반환한다.

### FR-8 분진 스코어 산출

구획별 값으로부터 패드 전체의 분진 스코어를 산출한다.

- 대표값은 평균이 아니라 최대 또는 상위 분위수를 사용한다. 국소 오염이 평균에 희석되지 않아야 한다
- 구획 값의 산포도 함께 반환한다. 산포가 크면 국소 뭉침, 작으면 균일 침착으로 해석된다
- 스코어의 부호 방향은 패드 톤에 따라 반대이므로, 패드 톤을 입력으로 받아 처리한다

### FR-9 보조 지표 산출

하단 선군의 각 굵기 단계에 대해, 선과 인접 여백 사이의 대비를 산출한다. 여백 방식과 선군 방식의 감도를 실증에서 비교하기 위한 항목이며, 상시 지표가 아니다.

### FR-10 TARGET_ID 판독

인쇄된 TARGET_ID 숫자를 판독하여 반환한다. 판독 실패는 판독 불가 사유로 처리하지 않고, 실패 상태로 반환한다.

### FR-11 중간 결과 출력

디버깅 및 실증 검증을 위해, 정면 보정된 이미지와 구획 분할 결과를 시각화한 이미지를 옵션으로 출력할 수 있어야 한다.

## 4. 입출력

### 입력

- 이미지 파일 경로 또는 이미지 데이터
- 패드 톤 (백색 바탕 / 흑색 바탕)
- 설정값 (임계값, 격자 분할 수 등)

### 출력

단일 결과 객체. 포함 항목은 다음과 같다.

- 판독 성공 여부
- 판독 불가 사유 (실패 시)
- 분진 스코어
- 구획 값 산포
- 구획별 값
- 제외된 구획 수 및 제외 사유별 내역
- 품질 게이트 산출값 (선명도, 포화율, 추정 각도, 패드 픽셀 크기)
- 선군 단계별 대비값
- 판독된 TARGET_ID
- 정면 보정 이미지 및 시각화 이미지 (옵션 요청 시)

주의: 본 모듈은 기준 이미지를 갖지 않으므로, 청정 상태 대비 변화량을 계산하지 않는다. 절대 측정값만 반환하고, 기준 대비 비교는 상위 계층에서 수행한다.

---

## 5. 비기능 요구사항

- 학습 기반 요소를 사용하지 않는다. 판독 근거가 설명 가능해야 한다
- 모듈은 상태를 갖지 않는다. 동일 입력에 대해 동일 출력을 반환한다
- 임계값과 파라미터는 코드에 하드코딩하지 않고 설정으로 분리한다. 실증 단계에서 반복 조정된다
- 처리 시간은 이미지 1장당 1초 이내를 목표로 한다

---

## 6. 확정되지 않은 사항

다음은 실증 데이터 확보 후 결정한다. 개발 단계에서는 조정 가능한 구조만 확보하면 된다.

- 품질 게이트 각 항목의 임계값
- 격자 분할 수
- 대표값 산출 시 사용할 분위수
- 채도 배제 임계값
- 분진 스코어와 실제 침착량의 관계(검량선) 및 정량 유효 구간 상한
- 패드 재질 및 점착 특성

---

## 7. 검증 방법

- 동일 패드를 여러 각도와 거리에서 촬영한 이미지에 대해, 정면 보정 후 분진 스코어가 일정 범위 내로 수렴하는지 확인
- 조명 조건을 변경한 이미지에 대해 스코어 변동이 억제되는지 확인
- 인위적으로 분진을 도포한 패드로 도포량 대비 스코어의 단조 증가 여부 확인
- 국소 뭉침 상태와 균일 침착 상태에 대해 구획 값 산포가 구분되는지 확인
- 흑색 바탕 패드와 백색 바탕 패드 모두에 대해 위 항목을 각각 검증
