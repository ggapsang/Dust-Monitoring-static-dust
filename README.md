# 참조 패드 분진 판독

에코프로비엠 포항 공장에서 AMR 이 순회하며 찍은 사진으로 분진 침착량을 읽는다.
관측 대상을 현장 표면이 아니라 규격이 정해진 **참조 패드**로 옮겨, 배경이
개소마다 다른 문제와 저빈도 방문으로 연속 현상을 못 잡는 문제를 함께 푼다.

    reader/     판독 모듈과 판독 서비스. 현장까지 가는 것
    padlab/     실증 관리 서버와 화면. 임계값을 채우기 위한 도구다
    assets/     패드 도안 생성기, 인쇄 폰트, 실촬영 표본
    ref/        현장 화면 시안. 동결이며 수정하지 않는다
    docs/       설계 문서
    requirements/  요구사항과 기획안 원본

## 띄우기

    docker compose up -d --build

    http://localhost:8911/docs    판독 서비스
    http://localhost:8912/        실증 관리 화면

## 두 가지를 나눈 이유

`reader/` 는 **무상태 순수 함수**다. 사진 두 장을 받아 분진 스코어를 내는 것이
전부이고, 시계열·기준 관리·화면을 갖지 않는다. 현장에서는 상위 시스템이 그
자리를 맡는다.

`padlab/` 은 그 상위 시스템을 실증 단계 동안 대신한다. 현장에 가면 버릴
것이므로 판독 모듈과 섞이지 않게 따로 두었다. 판독을 HTTP 로만 부르고 판독
로직을 한 줄도 갖지 않는다.

## 지금 어디까지 왔나

임계값이 대부분 비어 있다. **`null` 은 그 검사를 하지 않는다는 뜻**이고, 측정
자체는 항상 해서 결과에 실어 보낸다. 실증 분포를 보고 값을 채우는 순서를
강제하기 위해서다 — 거꾸로 임계값을 먼저 짐작해 넣으면 멀쩡한 사진이 걸러지고
있는지 알 방법이 없다.

자세한 것은 `docs/design.md` 와 각 디렉터리의 README 에 있다.
