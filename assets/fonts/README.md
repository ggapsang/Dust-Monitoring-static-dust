# POINT_ID 판독용 폰트

패드에 인쇄된 관측 개소 번호를 읽을 때 쓸 폰트를 이 폴더에 넣는다. 이 번호는
패드가 붙어 있는 물리적 개소를 가리키며, AMR 쪽 `TARGET_ID`(한 웨이포인트에서
PTZ 프리셋을 잡고 찍은 사진 한 장)와 같은 것이 아니다.

## 넣는 법

실제 인쇄에 쓴 폰트 파일(`.ttf`, `.otf`, `.ttc`) **하나**를 이 폴더에 복사한다.
파일 이름은 상관없다. 그 다음 컨테이너를 다시 띄운다.

```
docker compose restart padreader
```

## 왜 필요한가

POINT_ID 판독은 학습 모델이 아니라 **템플릿 매칭**이다. 0-9 를 직접 그려
놓고 사진에서 잘라낸 숫자와 모양이 얼마나 닮았는지를 잰다. 그리는 데 쓰는
폰트가 인쇄에 쓴 폰트와 다르면 닮은 정도가 떨어져 자리를 잘못 읽는다.

폴더가 비어 있으면 OpenCV 내장 스트로크 폰트로 그린다. 추가 설치가 필요
없는 대신 인쇄체와 획 굵기·형태가 달라 판독이 틀릴 수 있다.

## 여러 개를 넣으면

이름 순으로 첫 번째 파일만 쓴다. 무엇이 쓰였는지 헷갈리지 않도록 하나만
두는 것을 권한다.

## 폴더 위치를 바꾸려면

`config/default.yaml` 의 `point_id.font_dir` 을 고친다. 상대 경로는 설정
파일이 있는 폴더 기준이다. 실제로 어디를 보고 있는지는 `GET /config` 응답의
`values.point_id.font_dir` 에 절대 경로로 나온다.
